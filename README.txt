AMMU JI BIRTHDAY WEBSITE

How to open:
1. Keep index.html, styles.css, script.js, and the assets folder together.
2. Double-click index.html to open it in a browser.
3. For sharing online, upload the entire folder to any static hosting provider such as Netlify, GitHub Pages, Cloudflare Pages, or your own web server.

Notes:
- All 10 supplied photos are included in the assets folder.
- The site is responsive for mobile and desktop.
- Interactive buttons, popup joke, quiz, progress bar, reveal animations, and final surprise are included.
